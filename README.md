# mgr-nx

Нативный homebrew-порт **Metal Gear Rising: Revengeance** (Xbox 360) на Nintendo Switch через статическую рекомпиляцию.
Цель первой версии — вертикальный срез: пролог R-00, 60 кадров/с на Switch с разгоном. Рамки, решения и вехи — в [PLAN.md](PLAN.md),
журнал исследований — в [NOTES.md](NOTES.md), разборы форматов и движка — в `x360_work/*.md`.

**Игра в репозиторий не входит.** Здесь только инструменты, рантайм и документация. Порт собирается локально
из собственного диска пользователя (Xbox 360, TitleID 4B4E080A); код игры, перекомпилированный C++, шейдеры и ресурсы
генерируются на машине пользователя и не распространяются.

Основа рантайма — [rexglue-sdk-nx](https://github.com/nx-mod/rexglue-sdk-nx) (подмодуль `sdk/`, BSD-3-Clause).
Лицензия проекта — GPL-3.0 ([LICENSE](LICENSE)).
